LEVEL UP OS — PWA package

Содержимое:
- index.html — приложение
- manifest.webmanifest — параметры установки
- sw.js — офлайн-кэширование оболочки приложения
- icons/ — иконки

Установка на iPhone без App Store:
1. Разместить ВСЕ файлы и папку icons на HTTPS-хостинге (обязательно HTTPS).
2. Открыть опубликованный адрес в Safari на iPhone.
3. Нажать «Поделиться» → «На экран Домой».
4. Включить «Открывать как веб-приложение» (если пункт доступен) и нажать «Добавить».

Важно:
- Сам ZIP нельзя установить напрямую: PWA должна быть опубликована по HTTPS.
- После первой загрузки оболочка будет доступна офлайн благодаря service worker.
- Данные приложения сейчас хранятся локально в браузерном localStorage этого устройства/профиля.
- PIN в текущем прототипе — только экранная блокировка, не криптографическая защита данных.
- Для переноса данных между устройствами используйте встроенный экспорт/импорт JSON.
